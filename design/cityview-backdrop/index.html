Backdrop Style Options

Five procedural directions for a per-settlement city backdrop, generated from the settlement tile, its six neighbours and a seed. Each canvas is 1280×800 with the same opaque isometric grid and UI chrome so only the landscape changes.

Four seed variations per option, all at the selected scenario. Open a hero at ?capture=hero&option=biome-horizon&scenario=river-capital&seed=7.
